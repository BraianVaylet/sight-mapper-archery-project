# Sight Mapper Archery

PWA para arqueros que usan mira: registra donde va la mira a cada distancia para cada combinacion de
arco, mira y flechas, calcula las distancias que nunca tiraste (siempre marcadas como estimadas) y te
avisa cuando una marca probablemente este mal medida.
