# SetupCard

Tarjeta de un setup (arco + mira + flechas) en Inicio. Toda la tarjeta es el enlace.

- Nombre del arco en `display-md`; chevron a la derecha.
- Bloque tecnico en `sunken` con dos columnas rotuladas (`label`): Mira (en `mark`, es lo que identifica el setup) y Flechas.
- Pie: chapa "Acceso rapido" con icono de pin si la app abre en este setup; fecha en Plex Mono.
- Todas las tarjetas iguales (no destacar la primera con otro estilo): la jerarquia la da el orden y la chapa.

El consumidor provee: los nombres, fecha formateada, si es acceso rapido y el destino.
