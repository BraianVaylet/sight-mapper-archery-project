# SectionCard

Grupo titulado de campos. Rotulo de instrumento: indice `01` en `mark`, titulo `label` (Plex Mono MAYUSCULAS), regla punteada `line` y contador de campos completos.

- Panel `surface`, borde `border` 2px, `radius-md`, padding `space-4`.
- El indice numera las secciones de un formulario largo en orden (01, 02, 03): ayuda a ubicarse al volver a la pantalla.
- Elegir el nivel de encabezado (`h2`–`h4`) segun el esquema de la pagina.

El consumidor provee: `title`, `count` opcional, `as` y los hijos.
