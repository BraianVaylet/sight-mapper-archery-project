# BottomSheet

Hoja inferior para cargar o editar una marca sin salir de la pantalla de la mira. Al alcance del pulgar.

- Panel `surface`, borde `border`, esquinas superiores `radius-lg`, sombra `shadow-panel`; velo `sm-scrim` detras.
- `role="dialog"` + `aria-modal`, foco atrapado, cierra con Esc, con el boton y tocando el velo.
- Titulo `display-md`; campos numericos lado a lado; accion primaria de bloque (`touch-lg`) al final.

El consumidor provee: titulo, contenido y acciones.
