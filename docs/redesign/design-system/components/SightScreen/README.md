# SightScreen

Pantalla de la mira reacomodada, de arriba hacia abajo en orden de uso:

1. Cabecera: volver, nombre de la mira, setup y cantidad de marcas. Sin botones de tema.
2. Set de flechas (Select): cambia todo lo de abajo.
3. **ReadingHud**: distancia elegida y lectura, lo que se mira entre tiro y tiro.
4. **SightRuler**: regla + marcas; tocar elige distancia.
5. **ActionBar** fija abajo: herramientas, "Agregar marca" y tira de estado.

En 768+ el HUD y la escala van en dos columnas (escala a la derecha) y la ActionBar se vuelve una barra de herramientas sobre la escala.
